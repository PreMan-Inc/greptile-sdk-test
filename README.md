# greptile-sdk-test

Generated client SDKs for the Greptile Codex API.

Every file under this repository except this README and `.fernignore` is written
by PreMan. On each contract release it regenerates the clients from the same
OpenAPI document that produces the published reference at
<https://preman-inc.github.io/docs-test/>, and opens a pull request on a
`preman/sdk-*` branch.

Do not hand-edit generated sources; the next release overwrites them. To keep a
file, add its path to `.fernignore`.
